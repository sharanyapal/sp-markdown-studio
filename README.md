## At a glance

A deliberately safe Markdown previewer supporting headings, lists, links, emphasis, and code.

> **Design principle:** Make the behavior easy to explore, inspect and understand without hiding the implementation behind a service.

## The experience

- Live Markdown editor
- Safe HTML rendering
- Support for headings, links and inline code

## Quick start

```bash
python -m http.server 8000
```

Visit **http://localhost:8000/** in your browser. No package installation is needed for these static files.

- `index.html` — semantic interactive application page
- `style.css` — independent responsive art direction and components

A working portfolio-scale app, not a production security service. Local-only browser computation unless otherwise explained. No credentials are included.
